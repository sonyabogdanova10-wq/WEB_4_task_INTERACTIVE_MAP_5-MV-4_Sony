# NIGHT CITY REALTY

Учебный демонстрационный сайт на тему «Интерактивная карта и живой интерфейс бронирования». 
Создан с помощью нейросети DeepSeek на HTML/CSS/ванильном JS без использования сервера, сборки и платных сервисов карт.

## Тема
Бронирование жилья в мире Cyberpunk 2077: пользователь выбирает объект на карте Найт-Сити, изучает карточку, оформляет учебную бронь, управляет своими бронями и может отменить заказ.

## Запуск
1. Распакуйте архив.
2. Откройте папку `night_city_realty` в Visual Studio Code.
3. Запустите `index.html` через Live Server (или откройте файл браузером).

## Что реализовано
- адаптивная главная страница в неоновой эстетике киберпанка;
- схематичная интерактивная карта районов Найт-Сити;
- маркеры объектов жилья, выбор маркера открывает карточку объекта рядом;
- список объектов, поиск по названию/описанию, фильтры по району и типу;
- секция с подробностями по объекту;
- интерфейс бронирования с датами, количеством гостей и именем;
- автоматический расчёт стоимости по количеству ночей;
- проверка дат и вместимости объекта;
- экран подтверждения с демонстрационным номером бронирования;
- сохранение броней в localStorage и восстановление после обновления страницы;
- отмена брони освобождает объект;
- кнопка сброса демо.

## Ограничение
Учебное демо: бронирования сохраняются только в этом браузере. Реальные платежи, сервер, база данных и регистрация не подключены. Все объекты, координаты, цены и доступность вымышлены и используются как демонстрационные данные. Используются названия районов и общая эстетика вселенной Cyberpunk 2077; проект не связан с CD PROJEKT RED.

Проект разработан с помощью нейросети DeepSeek. Промпты, которые использовались для создания и улучшения сайта:

1. «Создай сайт бронирования сети домов "Night City Realty" на русском/английском языке. HTML/CSS/ванильный JS, без React, npm, сборки, сервера и платных карт. На странице: заголовок, фильтры, карта города через картинку именно, список апартаментов, область карточки выбранного дома и "Мои брони". Оформление в стиле киберпанка 2077 (игра). Подготовь рабочую базу с 9 домами, разными ценами и вместимостью, 3 дома премиум класса должны как-то выделяться через цвет маркера.»

2. «Добавь массив домов с полями id, название, описание, вместимость, ценаЗаНочь, координатыНаСхеме и занятость. Список и схема должны строиться по одним данным. У свободного, выбранного и занятого дома есть текстовая подпись и разное оформление. При выборе показывай описание и цену.»

3. «Сохраняй брони в localStorage и восстанавливай при обновлении страницы, включая занятость домов. Используй один ключ приложения, не очищай весь localStorage. Повреждённые данные или запрет сохранения должны показывать понятное сообщение, а не ломать страницу. Добавь кнопку сброса демо с подтверждением.»

## Структура
- `index.html` — разметка страниц и модальных окон
- `styles.css` — оформление и адаптивность
- `script.js` — данные объектов, карта, фильтры и логика бронирования
